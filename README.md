# HARDI Estate — Website Properti Premium

Website landing page properti premium, responsif, dengan estetika editorial dan animasi halus. Dibuat dengan HTML, CSS, dan JavaScript murni sehingga bisa dipublikasikan gratis melalui GitHub Pages.

## Fitur
- Desain premium dengan foto properti, tipografi editorial, dan animasi masuk.
- Responsif untuk desktop, tablet, dan ponsel.
- Filter koleksi berdasarkan kategori: rumah dan apartemen.
- Pencarian listing properti.
- Formulir konsultasi yang menyiapkan pesan WhatsApp.
- Navigasi mobile dan dukungan `prefers-reduced-motion`.
- Tidak membutuhkan build tools atau backend.

## Cara melihat di komputer
1. Ekstrak ZIP.
2. Buka `index.html` di browser.

## Cara mengaktifkan WhatsApp
1. Buka `script.js`.
2. Cari `const WHATSAPP_NUMBER = "6281234567890";`.
3. Nomor yang sudah diatur: `6285811320376`. Jika ingin menggantinya lagi, gunakan format internasional tanpa tanda `+`, spasi, atau tanda hubung.
4. Simpan dan uji formulir.

Nomor yang ada sekarang hanyalah placeholder contoh, bukan nomor kontak aktif.

## Cara publikasi ke GitHub Pages
1. Buat repository baru di GitHub.
2. Unggah `index.html`, `style.css`, `script.js`, dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/(root)`, lalu klik **Save**.
6. Tunggu proses publikasi selesai dan buka URL GitHub Pages yang diberikan.

## Sebelum dipublikasikan untuk bisnis sungguhan
- Ganti contoh nama, listing, harga, lokasi, email, dan foto sesuai data yang benar.
- Pastikan memiliki izin untuk menggunakan foto yang dipasang.
- Ubah nomor WhatsApp di `script.js`.
- Periksa seluruh informasi dan tautan di ponsel serta desktop.

## Catatan
Foto demo dimuat dari Unsplash dan font dari Google Fonts, jadi tampilan gambar/font memerlukan koneksi internet. Situs tetap berupa file statis dan tidak memerlukan server backend. Data properti pada versi demo bersifat ilustratif dan bukan penawaran properti nyata.
